APIs Nativas Utilizadas
Web Audio API Utiliza AudioContext, AnalyserNode para frequência/osciloscópio e conversão para buffer PCM WAV canônico.
MediaRecorder API Captura sem perdas do fluxo de microfone em chunks contínuos.
Web Speech API Reconhecimento contínuo de voz com SpeechRecognition / webkitSpeechRecognition.
Levenshtein Matrix Cálculo de similaridade de edição de texto com pontuação percentual e análise tokenizada por palavras.
