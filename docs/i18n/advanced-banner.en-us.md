# Periodic Advanced Banner

> Interactive cover banner (*cover*) with zoom animations and smooth text transition in *hover* effect, integrated with Bootstrap 5 and WordPress Block API v3.

---

## 📋 Overview

**Periodic Advanced Banner** is designed to create high-converting calls to action (CTAs), product highlight banners, promotions, and interactive headers. It combines an enriched visual layer with fluid hover transitions, allowing titles, captions and buttons to react instantly with modern micro-interactions.

---

## ✨ Main Features

- **Fluid Hover Animations**: Variations of zooming in (`zoom-in`), zooming out (`zoom-out`), smooth pan (`pan-right`), scale with subtle rotation and transition from black and white to color.
- **Dynamic Text Transitions**: Smooth lift effect (`slide-up`) with button reveal, opacity transition (`fade-in`) or scale.
- **Simulation in the Gutenberg Editor**: Exclusive button on the side panel that simulates the *hover* effect in real time without leaving editing mode.
- **Full Integration with Bootstrap 5**: Buttons and badges (*badges*) using standard Bootstrap classes (`btn-primary`, `btn-light`, `btn-outline-light`, `badge bg-primary`, etc.).
- **Native Responsiveness**: Independent adjustment of minimum height for large screens and mobile devices, in addition to scalable typography via `clamp()`.

---

## 🎛️ Control Panel Tabs (InspectorControls)

### 1. Content Tab
- **Seal / Badge**: Activation and customization of a stylized superior badge for categories or news.
- **Title & HTML Tag**: Editing the main title with choice of semantic hierarchy (`h2`, `h3` or `h4`).
- **Subtitle**: High-contrast descriptive complementary text.
- **CTA Button**: Activation, custom text, destination URL, option to open in new tab (`target="_blank"`) and Bootstrap 5 button palette.

### 2. Bottom Tab
- **Cover Image**: Upload or quickly select from the WordPress media library.
- **Image Focal Point**: Two-dimensional selector (`FocalPointPicker`) to center faces or main details.
- **Overlay**: Color palette for the translucent background and independent controls for standard opacity and *hover* opacity.

### 3. Hover Effects Tab
- **Simulate Hover Effect in the Editor**: Activation of the simulated state directly on the editing screen.
- **Image Effect**: Choose from 6 GPU-accelerated cinematic behaviors.
- **Effect on Text**: Definition of the physical and temporal transition of textual elements.

### 4. Layout tab
- **Content Alignment**: Alignment to the left (`text-start`), centered (`text-center`) or right (`text-end`).
- **Minimum Heights**: Specific settings for desktop (350px to 650px) and mobile (260px to 380px).
- **Border Radius**: Millimeter adjustment from 0px to 40px.
