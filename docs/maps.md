# Periodic Maps Block

A Gutenberg block that embeds responsive interactive maps (Google Maps, OpenStreetMap, etc.) with easy height, alignment, border‑radius and caption controls.

## Features
- Embed any iframe map URL.
- Adjustable height (200 – 1200 px).
- Alignment options (left, center, right, full width).
- Border radius customization.
- Optional caption below the map.
- Fully translatable (PT‑BR, EN‑US, ES‑ES, IT‑IT).

## Installation
1. Upload the `periodic-maps` folder to `/wp-content/plugins/`.
2. Activate the plugin from the WordPress admin.
3. Insert the **Mapa Interativo** block in the editor.
